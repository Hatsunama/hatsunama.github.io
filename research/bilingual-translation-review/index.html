A Translation Review That Can Say “Unresolved”

I'm learning how small local models and their surrounding software can support captions and translation. One useful next step is a review record that leaves room for uncertainty, including uncertainty in the review itself.

My translation candidate note left meaning quality open. This is a proposed way to investigate that question. The downloadable examples contain synthetic source sentences and empty output fields. No bilingual assessment or new model result is being reported here.

Freeze the text before judging it

Keep the exact source, language direction, surrounding context, model revision, runtime settings and raw translation together. For captions, also retain the cue identifier and a reference to the authorized recording. If the transcript is uncertain, record that first. A reviewer cannot settle an unclear source by choosing whichever translation sounds better.

Use synthetic or properly authorized material. Before sharing a case for review, remove identifying details that are unnecessary and make sure the reviewer is allowed to see the source.

Give each judgment its own field

Ask someone competent in both languages to compare the output directly with the source and its context. Record the intended audience or dialect when it affects the judgment. This proposed worksheet separates:

  • Meaning: are the people, actions, negation, time, quantities and qualifications preserved?
  • Naturalness: does the wording fit the intended target-language audience?
  • Mechanical behavior: did the output meet this candidate's documented format and the harness's parsing requirements?

For meaning and naturalness, use acceptable, needs correction, unresolved or not reviewed. Mechanical checks have their own pass, fail or not-tested status. A successful parser check should never fill in a missing meaning judgment.

Keep disagreements, then resolve what you can

Where a second bilingual reviewer is available, have them record their judgment before reading the first review. Keep both original judgments. If they disagree, record the exact disputed phrase, each explanation and any context needed to decide. An adjudicated decision belongs in a separate field; it should not overwrite the disagreement.

Consider the synthetic source “She said he might arrive tomorrow.” The review needs to account for the reported speaker, the person arriving, the possibility and the time reference. If the context does not identify a pronoun, do not invent an identity to make the case easier to score. Leave the relevant question unresolved.

A suggested correction belongs beside the original output. If it is later used for training or prompt development, mark the case as a development example. Keep a separate, previously unseen set for later evaluation.

Report coverage as well as decisions

Summarize each language direction separately. Count all selected cases, completed meaning reviews, cases needing correction, unresolved judgments and cases still awaiting review. Say how many reviewers participated and how disagreements were handled. If you calculate a percentage, name its denominator and show the unresolved and unreviewed counts alongside it.

A small synthetic review can help locate failures in those cases. It leaves other language directions, dialects, real-world audio conditions and application behavior open.

A reusable review record

Download the synthetic translation-review template (JSONL). It contains three English source cases with no generated translations, model identifiers or reviewer conclusions. Choose a target language, fill in the run details, preserve the raw output and add the actual reviews. The empty fields are intentional.

Each record keeps source uncertainty, raw output, mechanical checks, individual reviewer notes and adjudication separate. Duplicate the record for a new candidate rather than replacing an older run. It is a starting worksheet, not a validated benchmark or an implemented app feature.

Human First AI means keeping the speaker's meaning central and making it easy for a person to question the output. A useful review should make the remaining unknowns visible.
